# 听见 2.0 测试版验证记录

本记录区分实际运行检查、合成信号测试与界面回调测试。通过这些检查不等于已完成真机音准精度、延迟或独立安全审计。

## 自动检查

- `node tests/core_v2.cjs`：15597次断言通过。检查57章、84天与42天计划、30种指法、20种节奏、19套进行；核对各调中的借用/次属和弦与实际吉他按法；随机生成八类训练的答案及范围；验证敲击匹配、备份字段、旧笔记保留与错题复练状态。断言数量包含循环组合，不代表相同数量的独立人工测试。
- `PitchDetectorTest.java`：44次合成信号检查通过，包括基频、谐波、音分、静音、低音量、直流与噪声；实际44100Hz输入帧准备函数覆盖九个音高，包含六根空弦。此项没有真人录音，也不代表各种手机的测量误差。
- `python3 tests/ui_v2.py`：16组浏览器流程通过。实际触发Web Audio播放、完整听题后作答、错题两次复练、计划与笔记持久化、指板找音、和声移调、节奏计时、曲卡与变调夹、循环停止、JSON备份预览/取消/替换。没有敲击的完整节奏轮次得到真实零命中；中断轮次不记成完成。
- 浏览器音准界面检查通过显式模拟Native回调验证静音、音分、有效采样和分段推进；这只验证桥接契约与界面状态，不能当作真人唱准的证据。
- 五个主要页面在320、390、768、1280px宽度无横向溢出；三种音准设置在320、390px检查模式栏与表单独立布局。运行中无未捕获JS异常、无外部网络请求。
- `python3 tests/audit_assets.py`：68个WAV格式/内容、安装包ZIP、权限与备份声明检查通过，APK中不含签名私钥或密码。

## 安卓实际运行

在Android 9 / API28 x86模拟器、系统WebView66中检查，软件渲染、无硬件虚拟化加速。此环境偶有系统桌面无响应提示，不应混同为应用Java异常。

- 以相同包名与签名覆盖1.0，安装成功，版本号200 / 2.0.0；可以启动并操作新的五个入口。源码中保留旧版记录读取逻辑，浏览器回归检查确认旧笔记不被清除。
- 实际调用安卓系统文件选择器读取JSON，先显示摘要，确认后替换。再通过系统“保存”导出文件，使用ADB取回并解析核对：中文、U+2028、字面量HTML文本、已学章节、练习日分钟数、自定义和弦、歌词与变调夹均保留。
- 实际点击开始采音，AudioFlinger报告44100Hz、单声道PCM16、活动录音轨道；界面显示采音计时，无有效输入时保持0有效采样和空白命中率。切到安卓桌面时停止，AppOps录音时长固定在26.958秒；等待并重新回到应用后仍未增长，AudioFlinger活动录音轨道已移除，界面未把静音记为成绩。此项是模拟器真实麦克风API检查，没有模拟真人唱音。
- 本次检查期间AndroidRuntime日志未见应用Java崩溃。修复了音准设置页缺少闭合容器导致的小屏表单挤压，并在API28实际查看修复后的设置与测量页。

## 安全边界与限制

只声明RECORD_AUDIO，不声明网络或通用存储权限；录音不写文件、不上传。WebView只加载打包的本地资源，禁止文件访问和外部导航，CSP不允许外部脚本、连接或eval。附件只做静态数据提取和HTML白名单净化，未执行附件脚本；导入笔记/歌词中的HTML显示为文本。

原生文件读写仅访问用户选定URI，导入限制4MiB并校验结构。麦克风需用户主动开启，进入后台停止，Native端另设60秒上限。系统自动备份关闭。签名私钥与密码没有进入Git或APK。

未覆盖：真实安卓手机、真实人声/乐器录音准确率、各品牌麦克风/降噪与触屏延迟、蓝牙耳机、长时间续航、Android各大版本的文件选择器，以及独立安全审计。合成音频不能替代真实教师示范。弹唱与和弦转换没有自动演奏识别，不提供准确率。
