# 听见 1.0.0 验证记录

日期：2026 年 11 月 16 日（交付端日期）

## 已通过

1. **APK 构建**：Android SDK 35、build-tools 35.0.0、ECJ 3.40.0；Java 8 字节码经 D8 编译为 DEX，资源打包后进行 zipalign 对齐与独立 RSA 3072 位密钥签名。
2. **签名和结构**：`apksigner verify` 验证通过，v2 / v3 签名有效；APK ZIP 完整性、classes.dex 与离线资源检查通过；未包含私钥或签名密码。公钥证书信息另附。
3. **权限核查**：编译后 APK 只声明 RECORD_AUDIO，不声明 INTERNET；最低 API 26、目标 API 35；允许备份与明文通信均关闭。
4. **35 个音高算法断言**：实际执行 Java PitchDetector，检查多个频率的纯音与泛音叠加、±25 / ±50 音分、静音、低音量、直流与十组随机噪声。所测纯音 / 泛音估计误差小于 8 音分；这不是手机麦克风实测精度。
5. **14 项浏览器界面检查**：课程展开、自测与完成进度、笔记转义和持久化、实际 WAV 解码播放、声音筛选、权限拒绝反馈、有效 / 无效采样状态、五题听辨与统计、键盘按下释放、节拍器切换与退出停止、训练记录、删除确认等。
6. **宽度检查**：320、390、768、1280 像素下没有横向溢出；浏览器测试中无未捕获 JavaScript 异常或外部网络请求。
7. **内容检查**：18 节课程，每节包含 3 段讲解和有效自测答案；所有课程引用的音频存在；68 个 WAV 均为有效 22050 Hz / 单声道 / PCM16，包含非零音频数据。
8. **构建工具校验**：Gradle Wrapper JAR 与 Gradle 官方公布的 SHA-256 相符；发行包下载配置固定为 8.11.1，并配置发行包 SHA-256 校验。

## 已完成的安卓原生验证

环境为 Android 9 / API 28 AOSP x86 模拟器，系统 WebView 66；无硬件虚拟化，运行速度明显慢于正常手机。没有连接用户手机。

- 安装器返回 `Success`，最终 APK 启动返回 `Status: ok`。从模拟器中取回已安装的 base.apk，SHA-256 与最终交付 APK 一致。
- 通过实际截图检查中文首页、练习页、音高训练页及声音库，确认本地 HTML / CSS / JS 在安卓 WebView 中加载并可以操作。较旧 WebView 的品牌间距与窄屏标题已作兼容调整。
- 点击开始训练后出现真实的安卓 RECORD_AUDIO 权限框；拒绝后回到可再次训练状态，并显示未授权反馈；再次点击能够重新申请。
- 允许授权后，原生 AudioRecord 进入采集状态，界面计时并处理无声输入，显示“暂时无法判断音高”，没有生成虚构成绩。
- 按 Home 进入后台后，系统 AppOps 记录的麦克风使用时长固定为 `17s693ms`；间隔约 26 秒再次查询时，时长仍为同一数值。回到应用显示“再练一次”，原生采音没有自动继续。
- 声音库中点播离线五声音阶后，AudioFlinger 中出现该应用进程的活动音频轨道，采样率 22050 Hz，确认已进入安卓音频输出链路。模拟器禁用了宿主音频输出，没有用耳朵或物理设备评估实际听感、延迟和扬声器音量。
- 最终快检检查了已安装应用的前台窗口、非空画面及无 Java 崩溃；页面内容由实际截图人工核对。源码附有对应检查脚本与日志。

## 原生测试中的环境问题

最初使用的 Android 11 Google APIs 镜像在软件模拟环境中反复发生系统服务超时，未形成稳定运行验收。Android 9 镜像首次启动和安装 WebView 缓存初始化时，也曾弹出 **System UI** 无响应提示。处理系统提示并等待初始化后，完成了上面的业务流程检查。

旧 WebView 未向此环境的 UIAutomator 提供完整网页文本树，使用文本树判断页面内容的早期检查因此失败。最终脚本改为检查窗口焦点、截图是否非空及 Java 崩溃日志，网页内容由目视核查；这项检查不能替代完整的安卓自动化 UI 测试。保留早期失败日志，未把它们计作通过。

## 仍未覆盖

**尚未进行任何真机收音、真实人声的音准误差、音频延迟、耳机插拔、来电中断及多品牌机型测试。** 最低 Android 8.0 与目标 API 35 是构建配置；此次实际运行验证限于 Android 9 模拟器，不代表所有系统版本与设备均已验收。

浏览器音高测试使用模拟 nativeState / nativePitch 回调验证显示和统计，不代表录到了人声。安卓原生测试确实启动了麦克风采集，但输入为模拟器静音，没有据此宣称测得真人音高。交付的《界面预览.png》使用未产生测量值的界面状态，不包含虚构成绩。

当前版本没有经过独立安全审计，也没有执行应用商店发布审核。Gradle / Android Studio 入口已配置并附 Wrapper，本次 APK 实际使用 `build.sh` 构建，没有再次运行完整 Gradle 构建。
