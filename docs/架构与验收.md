# 架构与后续验收

## 数据路径

用户点击开始 → 安卓请求 RECORD_AUDIO → AudioRecord（MIC、22050 Hz、PCM16、单声道） → 2048 样本内存帧 → RMS / YIN → 有效频率与置信度 → 界面显示 → 结束时仅写入数字摘要。

音频帧不写文件。声音源来自用户主动启动的前台训练；所有 Activity onPause（权限对话框阶段除外）同步停止录音，onDestroy 释放资源。首次授权可能触发 Activity 暂停，因此通过 pending / resume 标记确保授权结果只在前台恢复后启动。

课程与音频 → 只读安装包 assets → 精确限定的 HTTPS 虚拟来源拦截 → 封闭 WebView。

进度 / 笔记 / 训练摘要 → 私有 WebView localStorage → 本地删除确认；应用不提供系统备份。

## 质量范围

这是可安装的 1.0.0 个人学习版本，覆盖一条从阅读、听示范、自测到训练复盘的完整路径。课程面向基础学习，未实现高级曲谱编辑、歌曲伴奏库、整曲评分、多设备同步或第三方网页导入。

## 真机验收建议

1. Android 8、11、15/16 的至少一台目标设备：首次启动、页面与返回键。
2. 首次麦克风允许 / 拒绝 / 永久拒绝后从系统设置恢复权限。
3. 使用耳机，从乐器或标准音源对照 A3、C4、A4；分别测试基音、偏高、偏低、八度错误。
4. 有声训练中按 Home、锁屏、切换应用：系统麦克风指示消失，回到应用需重新点击训练。
5. 手机静音、耳机插拔、来电中断、其他录音应用占用后的恢复。
6. 飞行模式：课程、WAV、听辨、键盘和节拍器可用。
7. 系统最大字号、横屏、窄屏、手势导航、刘海区域与深色系统外观。
8. 清除记录、卸载重装、不同签名更新时的数据与安装提示。
